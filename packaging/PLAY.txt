Anoma: Minecraft Java Edition 26.3, rewritten in Rust
=========================================================

Anoma is an unofficial fan project, not affiliated with, endorsed by or
connected to Mojang Studios or Microsoft. Minecraft is a trademark of Mojang
and Microsoft. This folder contains none of Minecraft's code, textures or
sounds: Anoma prepares them from your own copy of Minecraft Java Edition.

Playing through the Anoma launcher
  Nothing to do here: the launcher installed this folder, prepares the
  resources the first time you press Play, and starts the game. Use the
  launcher to update, play or run a server.

Downloaded this archive directly?
  Get the launcher instead; it installs, prepares and updates Anoma for you:
  https://github.com/JeremGamingYT/Anoma/releases?q=launcher-v&expanded=true
  More about Anoma: https://playanoma.dev

  To prepare this folder by hand you need Minecraft Java Edition 26.3, played
  once from the official launcher, and a Java 25 runtime. Then, in this folder:
    ./anoma-prepare --prepare --server-jar PATH/TO/server.jar
    ./anoma-prepare sounds               (optional, for sound)
  (Windows: anoma-prepare.exe.) The 26.3 server jar is the downloads.server.url
  in your launcher's versions/26.3/26.3.json. Add --minecraft-dir PATH to both if
  your launcher keeps the game elsewhere. Then run
  ./anoma-client (anoma-client.exe on Windows; on macOS the first time:
  right-click > Open). anoma-client --help lists the options.

Controls: mouse look, WASD move, Space jump, Left Shift sneak, Left Ctrl
sprint, left click break, right click place/use, 1-9 or scroll for the hotbar,
E inventory, Q drop, F1 hide the HUD, F3 debug, Esc pause.

Scripts and AI agents
  anoma-ctl, in this folder, plays the game from a terminal or a script:
    ./anoma-ctl launch --world Test --wait     (anoma-ctl.exe on Windows)
    ./anoma-ctl state
    ./anoma-ctl help                           lists every command
  anoma-ctl mcp is an MCP server for AI agents (stdio; add it to your MCP
  client as the command anoma-ctl with the argument mcp). It finds the game
  beside it or the version the launcher installed.

Running a server
  anoma-server, in this folder, hosts a server with this game as its engine,
  using the resources prepared above:
    ./anoma-server --dir my-server init     the EULA, world, seed, port, who may join
    ./anoma-server --dir my-server start    in the background; also stop, restart
    ./anoma-server --dir my-server status   TPS, MSPT, players, RAM and CPU
    ./anoma-server --dir my-server cmd list
    ./anoma-server --dir my-server backup   also backups, restore
    ./anoma-server --dir my-server service install   start it at boot or login
  Its settings are in my-server/server.toml. ./anoma-server help lists every
  command; docs/server.md in the repository has the details.
